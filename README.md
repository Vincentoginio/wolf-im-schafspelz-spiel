# Wolf im Schafspelz

Ein Hirtenspiel im Browser: Schafe einsammeln, den getarnten Wolf entlarven und durch den dunklen Wald zum Hochsitz der Jäger fliehen.

**Spielen:** https://vincentoginio.github.io/wolf-im-schafspelz-spiel/

- `mobil.html`: Version für Handy und iPad
- `spiel.html`: Version für Computer

Die 3D-Grafik nutzt [three.js](https://threejs.org) r128 (MIT-Lizenz), eingebettet in die Dateien.
